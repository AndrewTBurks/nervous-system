# Intent Retention and Task Writing

`.cns/intent.md` is the visible work ledger. Completed tasks stay visible and are marked done. Do not delete completed entries as cleanup.

## Adding tasks

- Read existing intent first.
- Consolidate overlap before appending.
- Append at the end with the next sequential number.
- Preserve user corrections.
- Put judgment calls in explicit sub-bullets.

## From audit to intent

Group findings by coherent change, not by file count or decision ID. Prefer one consolidated task when a survey overlaps existing queued work.
