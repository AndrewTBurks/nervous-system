# /nervous-system plan

## Purpose

Collect upcoming work and write approved tasks into `.cns/intent.md`.

## Preflight

1. Run common preflight.
2. Read full `.cns/intent.md`.
3. List `.cns/plans/`.
4. Check recent log entries for active planning context.
5. If existing plan files contain Q&A, read them before asking repeated questions.

## Procedure

1. Let the user dump the full list of requested work.
2. Ask clarifying questions only where ambiguity changes implementation.
3. Consolidate overlap with existing intent before adding new tasks.
4. Append new tasks at the end with the next sequential task number.
5. Preserve completed tasks; mark obsolete overlaps done instead of deleting them.
6. Read back `intent.md` after writing.
7. Run health.

## Planning interaction rule

For open-ended task intake, keep asking for additional feedback until the user says done. For bounded design-session tasks, present a prepared brief with options, recommendation, and one clear question.

## Output

List the added/changed task numbers and any unresolved pivots.
